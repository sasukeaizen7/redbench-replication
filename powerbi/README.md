# Power BI dashboard

Five pages over `results/`: **Scorecard** (every claim, paper vs replication, verdicts), **Repetition (Table 4)**, **Metric definitions** (the three implementations in the authors' code), **Fleet** (query mix, CPU skew, string filters) and **Clusters** (repetition of every Redset database with ≥ 1,000 selects in May 2024).

```bash
python powerbi/build_pbip.py      # results/*.csv -> powerbi/data/*.csv + the .pbip project
```

Open `powerbi/Redbench.pbip` in Power BI Desktop and click **Refresh**. The project is plain text: TMDL model in `Redbench.SemanticModel/`, PBIR report in `Redbench.Report/` (one JSON per page and visual), all generated by `build_pbip.py`. Edit the script rather than the files, because a rebuild overwrites them. Changes made in Desktop are lost on the next rebuild unless you port them back into the script.

The Power Query parameter `DataFolder` holds the absolute path to `powerbi/data/`. The script sets it to the folder it runs from.
